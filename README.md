# تنظيم ملفات CSS — Green Bahri

## القاعدة العامة
- `style.css`: القواعد المشتركة بين جميع الصفحات (المتغيرات، الخطوط، reset، الأزرار، navbar، footer، المكونات العامة).
- `home.css`: تنسيقات الصفحة الرئيسية فقط.
- `map.css`: تنسيقات الخريطة فقط.
- `colleges.css`: تنسيقات مساهمات الكليات فقط.
- `trees.css`: تنسيقات دليل الأشجار فقط.
- `gallery.css`: تنسيقات معرض المبادرة فقط.
- `certificate.css`: تنسيقات شهادة الزراعة فقط.

## ترتيب الاستدعاء
كل صفحة تستدعي `style.css` أولاً، ثم ملف CSS الخاص بها. هذا يسمح لقواعد الصفحة أن تخصص أو تتجاوز القواعد العامة عند الحاجة.

## مهم قبل نقل القواعد الحالية
ملف `style.css` الحالي يحتوي على قواعد عامة وقواعد خاصة بعدة صفحات مختلطة معاً. لذلك أُنشئت ملفات الصفحات وربطت بصفحاتها، لكن لم تُنقل القواعد الحالية تلقائياً حتى لا يتغير شكل الموقع أو تتعطل أجزاء منه. انقلوا القواعد الخاصة بصفحة واحدة في كل مرة، ثم اختبروا الصفحة على الكمبيوتر والموبايل والوضع الداكن قبل اعتماد النقل.

## توزيع المسؤولية المقترح
- مدير المشروع / الصفحة الرئيسية: `index.html`, `js/home.js`, `css/home.css`.
- مطور الخريطة: `map.html`, `js/map.js`, `css/map.css`.
- مطور الكليات: `colleges.html`, `js/colleges.js`, `css/colleges.css`.
- مسؤول المحتوى: يجهز النصوص والبيانات في مستند/ملف محتوى مستقل، ولا يعدّل ملفات HTML أو `style.css` مباشرة إلا بالتنسيق مع المطور المسؤول.
- مسؤول واحد فقط يراجع تعديلات `css/style.css` لأنه مشترك بين الصفحات.
